# Travel Time Calculator

Невеликий Python-додаток для розрахунку загального часу подорожі.
Дозволяє підсумовувати тривалість маршруту та виводити її у зручному форматі (годинник + хвилина).

---

## Можливості

* Підрахунок загального часу маршруту
* Форматування часу в вид, що читається
* Вбудовані тести:

  * **doctest** (всередині функцій)
  * **unit tests** (через unittest)

---

## Завантаження

1. Схиляти репозиторій:

``` bash
git clone https://github.com/artemijMoskowsky/imp_l5
```

2. Перейти до папки проекту:

``` bash

```

## Запуск

Запуск основної програми:

``` bash
python main.py
```

Приклад висновку:

