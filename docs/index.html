Travel Time Calculator

Невеликий Python-додаток для розрахунку загального часу подорожі. Дозволяє підсумовувати тривалість маршруту та виводити її у зручному форматі (годинник + хвилина).

Можливості

  • Підрахунок загального часу маршруту
  • Форматування часу в вид, що читається

  • Вбудовані тести:

  • doctest (всередині функцій)

  • unit tests (через unittest)

Завантаження

  1. Склонувати репозиторій:
git clone https://github.com/artemijMoskowsky/imp_l5
  1. Перейти до папки проекту:
cd imp_l5

Запуск

Запуск основної програми:

python main.py

Приклад висновку:

Загальна година: 2 рік 55 хв

Запуск тестів

Усі тести запускаються автоматично разом із програмою:

python main.py

Структура проекта

travel-time-calculator/
│
├── main.py          # Основний код + тести
├── README.md        # Документація

Приклади використання

route = [50, 35, 90]
total = calculate_total_minutes(route)
print(format_travel_time(total))

Вимоги

  • Python 3.8+

Нотатки

  • calculate_total_minutes - вважає загальний час
  • format_travel_time - форматує результат
  • Проект зроблено як навчальний приклад (з тестами)
